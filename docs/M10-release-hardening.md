## Release manifest (§28)

Generated by `scripts/release-manifest.ps1` →
`target/release/MANIFEST.txt`: version, identifier, git commit/branch/
dirty-status, rustc/cargo versions, node/pnpm versions, SHA-256 of
exe/installer/Cargo.lock/pnpm-lock.yaml, UTC timestamp, signing
status. No username, absolute path or secret (§28 rule).

## Signing (§26)

FACT: no certificate exists yet. DOCUMENTED path (§26 checklist):
1. Acquire OV/EV certificate (M11 decision — NOT purchased in M10).
2. Configure Tauri bundler signing via env vars in the release CI
   only (`TAURI_SIGNING_*` / signtool parameters) — never in-repo.
3. SHA-256 timestamped signature on exe + installer.
4. Publish signing procedure + verify with `signtool verify /pa`.

SmartScreen note: unsigned builds WILL trigger SmartScreen; signing
reduces but does not eliminate reputation warnings (§26).
